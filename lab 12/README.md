# Лабораторная работа №12 — вариант 8

**Дисциплина:** Парадигмы программирования (PP 2205)  
**Тема:** Реактивное и асинхронное программирование. Потоки данных  
**Вариант 8:** Уведомления студентам

## Описание

Программа моделирует асинхронную отправку уведомлений студентам. Производитель помещает сообщения в ограниченную очередь `asyncio.Queue(maxsize=3)`, а два потребителя независимо обрабатывают задания.

Временные ошибки отправки обрабатываются повторными попытками с экспоненциальной задержкой. После исчерпания лимита попыток уведомление попадает в список ошибок.

## Схема

```text
Список уведомлений
        |
        v
   Producer
        |
        v
 asyncio.Queue (maxsize=3)
       / \
      v   v
 worker-1 worker-2
      \   /
       v v
 Успешные отправки / Ошибки
        |
        v
 Итоговая статистика
```

## Требования

- Python 3.11 или новее
- Внешние библиотеки не требуются

## Запуск

```bash
python main.py
```

## Запуск тестов

```bash
python -m unittest -v
```

В тестовом наборе проверяются корректные и некорректные адреса, пустые тема и текст, отрицательное число временных ошибок, успешная отправка, повторные попытки, превышение лимита повторов и пустой вход.

## Реализованные конструкции

- `async def` и `await` — асинхронные функции;
- `asyncio.create_task` — параллельный запуск двух потребителей;
- `asyncio.Queue(maxsize=3)` — ограниченный буфер и обратное давление;
- `SENTINEL` — сигнал корректного завершения;
- `task_done()` и `join()` — контроль обработки элементов очереди;
- `asyncio.sleep()` — имитация сетевой задержки без блокировки цикла событий;
- повторные попытки с экспоненциальной задержкой.
